Notes / known limitations
-------------------------
* The APK is a phone client for the "DS Bot" host bridge (host/dsbot-bridge.mjs);
  it never talks to DSH directly and never holds the DSH browser cookie.
* Bridge <-> phone traffic is cleartext HTTP on the trusted LAN (device token).
* Bot orchestration runs on the phone; DSH sessions stay on the computer.
* No on-device screenshot in this build environment (the sandbox cannot start
  QEMU/WHPX; Chrome CDP is also blocked). UI was implemented against the DSH web
  design tokens and every screen has compiled @Preview data.
* Install/use guide: docs/INSTALL.md ; protocol: docs/PROTOCOL.md ;
  security model: docs/SECURITY.md ; UI contract: docs/UI-CONTRACT.md.
